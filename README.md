# Анна Ковалева — новая версия сайта (тёплая коричнево-бежевая гамма)

Односторонний сайт без сборки: открывается двойным кликом по `index.html`.
Тот же функционал, что у `anna-kovaleva`: бронирование через WhatsApp, прайс с вкладками,
галерея работ с фильтром, отзывы, подарочный сертификат с видео, контакты и карта.

Все настройки (телефон, цены, расписание, фото, отзывы) лежат в блоке `НАСТРОЙКИ` в конце `index.html`.

Дизайн: тёмный первый экран, крупные тонкие заголовки, акцент — один (`--tan`),
одна главная кнопка и одна контурная. Цвета и радиусы — в `:root` в начале `<style>`.
