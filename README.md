# Сайт Анни Ковальової — Бат-Ям

Односторінковий сайт без збірки і залежностей. Відкривається подвійним кліком по `index.html`.
Стокових зображень не залишилось: усі фото реальні.

```
index.html          65 КБ
assets/            1.5 МБ
```

## Що зроблено

**Контент.** Дев'ять блоків: перший екран, послуги, підхід, прайс, роботи, відгуки,
подарунковий сертифікат, бронювання, контакти.

**Дані з картки Google.** Адреса з номером будинку (רחוב התחייה 1), телефон, години,
рейтинг 5,0 з посиланням на картку, вбудована мапа, кнопка «Залишити відгук»
веде одразу у форму Google.

**Обладнання.** Лазер INMODE і косметика GIGI — знято з листівки і халата на фото.

**Фото.** Одинадцять реальних знімків: процедури, апарати, робочий процес.
Кольори вирівняні під палітру — сині рукавички приглушені, все зведено в тепло.

**Ілюстрації.** Картка «Манікюр і педикюр» — намальований SVG у стилі сертифіката
(4,5 КБ, анімований). Ролик з феєю живе в блоці сертифіката: постер розчиняється
у відео зі спалахом.

**Бронювання.** Три кроки — послуга, день, час. Збирає заявку і відкриває WhatsApp
з готовим текстом. Субота вимкнена.

**Технічне.** Іконка сайту, прев'ю для WhatsApp і Telegram, розмітка Schema.org
BeautySalon для пошуку, мобільна версія на п'яти брейкпоінтах, підтримка
`prefers-reduced-motion`, порожні стани для фільтрів і відгуків.

## Що залишилось — потрібна Анна

### 1. Ціни — обов'язково
Зараз орієнтир по ринку Бат-Яма, я їх **вигадав**. Публікувати не можна.
Правити в `PRICES` на початку `<script>`, три вкладки.

### 2. Згода клієнток на фото — обов'язково
На шести знімках обличчя впізнавані. Потрібен дозвіл на публікацію,
достатньо переписки. Безпечний виняток — кадр із маскою, там обличчя закрите.

### 3. Години прийому
Взято з Google: Нд–Пт 08:00–20:00, субота вихідна. Підтвердити.
Якщо п'ятниця коротка — правити в `SCHEDULE`, рядок `5:`.

### 4. Фото манікюру
Єдина діра. Потрібно 4–6 знімків: апаратний манікюр, гель-лак, педикюр,
зміцнення. Формати 3:4 і 1:1. Зараз фільтр «Нігті» показує чесне
повідомлення «фото скоро з'являться».

### 5. Відгуки
Три слоти в `REVIEWS` порожні — блок показує лише плашку рейтингу.
Скопіювати тексти з картки Google:

```js
{ name:"Марина", date:"липень 2026", stars:5, text:"..." }
```

### 6. Листівка INMODE
Не поставив: це рекламний макет виробника з їхньою моделлю.
Якщо Анні видали маркетинг-кіт із дозволом — скажи, додам.

## Де що міняти

Усе на початку `<script>`:

| Змінна | Що це |
|---|---|
| `PHONE` | телефон для WhatsApp і дзвінка |
| `MAP`, `PLACE_ID` | картка Google і форма відгуку |
| `IG` | два акаунти Instagram |
| `PRICES` | прайс, три вкладки |
| `REVIEWS` | відгуки |
| `SCHEDULE` | години для бронювання, 0 = неділя |
| `PHOTOS` | шляхи до фото |
| `VIDEO`, `POSTER` | ролик і постер у блоці сертифіката |

**Палітра 60 / 30 / 10** — у `:root` на початку `<style>`:
60% білий фон, 30% зелений (секції, тёмні панелі, стрічка), 10% малиновий —
тільки на головних кнопках і в підписах під заголовками. Маркери, цифри, точки
й рамки зелені (`--detail`). Усі пари перевірені на WCAG AA —
мінімум 4.5:1. Нижче закоментована запасна вишнево-золота палітра.

**Шрифт — один.** Manrope, три ваги: 400 текст, 600 підзаголовки, 800 заголовки.
Prata і Marck Script прибрані — ієрархія будується вагою, розміром і регістром,
як вимагає швейцарська школа. Мінус два шрифтових файли при завантаженні.
Заголовки — 800, CAPS, трекінг −3%. Підзаголовки-розчерки — 400, малі літери:
контраст за вагою і регістром замість другої гарнітури.

**Типошкала** — база 16 px, коефіцієнт 1.25, дев'ять рівнів у токенах `--t0`…`--t8`.
Жодного «розміру на око»: у стилях лишилось одне сире значення — 16 px бази.
Ваги: три (400 / 600 / 800) замість шести — шрифт вантажиться втричі легше.
Трекінг за ролями: `--tr-disp` −3% на великих заголовках, `--tr-caps` +18%
на CAPS-мітках, звичайний текст 0.

**Радіуси** — п'ять ступенів у токенах `--r-xs` / `--r-sm` / `--r-md` / `--r-lg` / `--r-pill`;
`--r-sm` 6px — для плашок-міток (`.eyebrow`).
Випадкових значень немає.

**Сітка.** Усі відступи кратні 8 px (було 34 випадкових значення, лишилось 17 на сітці).
Колонки діляться націло: 7:5 на першому екрані, 5:7 у «Підході», 7:5 у сертифікаті.
Поля секцій — до 128 px на десктопі.

## Анімації — перенесені з foxyarizot.com

Узято з `app/fx-effects.css` вашого сайту, кольори адаптовані під зелено-малинову палітру.
Без бібліотек, усе на CSS + невеликий JS.

| Клас | Що робить | Де застосовано |
|---|---|---|
| `fx-words` / `fx-w` | заголовок проявляється по словах із розмиттям | головний екран |
| `fx-rise` | поява при прокрутці з розмиттям і масштабом (замінила просте зрушення) | усі блоки `.rv` |
| `fx-glare` | білий блик по фото — сам раз на 6,5 с і одразу при наведенні | головне фото, картки послуг |
| `fx-beam` | бігуча обводка кнопки | «Забронювати час» |
| `fx-spot` | м'яке зелене світло за курсором | картки послуг |
| `fx-tilt` | 3D-нахил картки за мишею | картки послуг |
| `fx-num` | ціна набігає від нуля | прайс |

Сходинкова затримка в групах — 110 мс між сусідами, як у `RevealGroup.tsx`.
Світло й нахил працюють лише там, де є миша (`hover: hover and pointer: fine`).
Усе вимикається при системному «менше руху».

## Оптимізація швидкості

За звітом PageSpeed зроблено:

- **Шрифти не блокують відмальовку** — підключені через `media="print"` з перемиканням
  після завантаження. Текст з'являється одразу системним шрифтом, потім підміняється.
- **Головне фото вантажиться першим** — `rel="preload"` і `fetchpriority="high"`.
  Це елемент LCP, він більше не чекає своєї черги.
- **Ролик не вантажиться при відкритті** — `preload="none"`, файл підтягується і
  стартує лише коли доскролили до блока сертифіката. Мінус 874 КБ зі старту.
- **Нижні секції не малюються завчасно** — `content-visibility:auto`.
  Браузер пропускає їх, поки вони за екраном.
- **Частинки малюються в простої** — через `requestIdleCallback`, не заважають
  першій відмальовці.

Перевіряти після публікації: pagespeed.web.dev, вкладка «Мобільні пристрої».
